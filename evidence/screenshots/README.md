# Coverage screenshots (demo evidence)

Captured 2026-10-21 by opening the committed HTML reports in a browser and taking a
full-viewport screenshot. No coverage data was regenerated for these images — every
number shown is produced by the committed HTML under `evidence/baseline_coverage/html/`
and `evidence/coverage/final/html/`.

| File | Shows | Key numbers |
|---|---|---|
| `01-baseline-coverage-index.png` | **BEFORE** — baseline LCOV index (`evidence/baseline_coverage/html/index.html`) | Test `failsafe_scope.info`, date 2026-10-01, **Lines 81.0 % (281/347)**, **Functions 93.8 % (30/32)**, **no branch row** (upstream lcov run without `--rc branch_coverage=1`) |
| `02-baseline-framework-annotated-source.png` | **BEFORE** — annotated `framework.cpp` source at baseline (`evidence/baseline_coverage/html/failsafe/framework.cpp.gcov.html`) | **Lines 80.4 % (266/331)**, **Functions 94.1 % (16/17)** — uncovered lines visible in red |
| `03-final-coverage-index.png` | **AFTER** — final LCOV index (`evidence/coverage/final/html/index.html`) | Test `failsafe_student_scope.info`, date 2026-10-08, **Lines 100.0 % (366/366)**, **Functions 100.0 % (32/32)**, **Branches 90.8 % (385/424)** |

## What to say when showing these
- The baseline is **81 %, not 0 %** — PX4 already ships its own failsafe tests. We never
  claimed a 0 % start; the before/after delta is **81.0 % → 100.0 % lines** (+85 lines),
  **30/32 → 32/32 functions**, and branch coverage was captured for the first time by our
  suite (**0 → 385/424 legs**).
- Different lcov versions are visible in the footers (baseline generated by LCOV 2.0-1 on
  Fedora, final by LCOV 1.16 on Ubuntu 24.04) — that is the two-machine setup, and it is
  expected.

## Reproducing the screenshots yourself
Open these two files in any browser and press `Win + Shift + S`:
```
evidence/baseline_coverage/html/index.html
evidence/coverage/final/html/index.html
evidence/baseline_coverage/html/failsafe/framework.cpp.gcov.html
evidence/coverage/final/html/failsafe/framework.cpp.gcov.html
```
